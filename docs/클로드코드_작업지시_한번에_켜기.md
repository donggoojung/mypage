# 클로드 코드 작업 지시서: 판매 프로그램을 더블클릭 한 번으로 켜고 끄기

이 문서는 판매 노트북(윈도우)에서 실행 중인 클로드 코드에게 주는 작업 지시서입니다.
대표님은 컴퓨터 명령어에 익숙하지 않습니다. 모든 설명과 보고는 **쉬운 한국어**로 하고, 영어 용어는 쓰지 말거나 꼭 필요하면 괄호로 뜻을 붙여 주세요.

## 목표

지금은 판매 프로그램을 켤 때마다 PowerShell 창 3~4개를 열고 명령어를 직접 쳐야 합니다.
이것을 **바탕화면 아이콘 더블클릭 한 번**으로 끝나게 만듭니다.

- `보탬 켜기` 아이콘: 도커 켜기 → 최신 코드 받기 → 데이터베이스 표 갱신 → 서버·작업자·예약 작업 켜기 → 브라우저로 농산물 화면 열기
- `보탬 끄기` 아이콘: 서버·작업자·예약 작업 끄기

## 이 컴퓨터의 상황 (확인된 사실)

| 항목 | 값 |
| --- | --- |
| 운영체제 | 윈도우 |
| 프로젝트 폴더 | `C:\Users\SSNPC\projects\mypage` |
| 판매 프로그램 폴더 | `C:\Users\SSNPC\projects\mypage\backend` |
| 파이썬 가상환경 | `backend\.venv` (켜기: `.venv\Scripts\Activate.ps1`) |
| 작업 브랜치 | `claude/amazing-cannon-fjkoca` |
| 데이터베이스·대기열 | 도커 데스크톱 위에서 PostgreSQL 16, Redis (`backend\docker-compose.yml`) |
| 데이터베이스 표 갱신 | `alembic upgrade head` (backend 폴더에서) |
| 서버 | `uvicorn app.main:app --port 8080` |
| 작업자 | `celery -A app.core.celery_app worker --loglevel=info --pool=solo` |
| 예약 작업 | `celery -A app.core.celery_app beat --loglevel=info` |
| 상태 확인 주소 | `http://localhost:8080/health` (정상이면 `{"status":"ok"}`) |
| 화면 주소 | 신발 `http://localhost:8080/`, 농산물 `http://localhost:8080/agri.html` |

위 명령은 모두 `backend` 폴더에서, 가상환경을 켠 상태로 실행해야 합니다.

## 할 일

### 1. 최신 코드 받기
- `git status`로 이 노트북에 저장 안 된 변경이 있는지 먼저 봅니다.
- 변경이 없으면 `git pull origin claude/amazing-cannon-fjkoca`.
- 변경이 있으면 **지우지 말고** 어떤 파일인지 대표님께 쉬운 말로 알려드리고 어떻게 할지 물어봅니다.

### 2. 켜기 스크립트 `backend\scripts\start_all.ps1` 만들기
순서대로 하고, 단계마다 화면에 한국어로 "[1/6] 도커를 켜는 중..."처럼 보여 줍니다.

1. **도커 확인**: `docker info`가 실패하면 도커 데스크톱을 실행합니다 (보통 `C:\Program Files\Docker\Docker\Docker Desktop.exe`, 이 노트북의 실제 위치를 확인하세요). 준비될 때까지 최대 3분 기다립니다.
2. **데이터베이스·대기열 켜기**: backend 폴더에서 `docker compose up -d` (안 되면 `docker-compose up -d`). 5432번, 6379번 연결이 될 때까지 기다립니다.
3. **이미 켜져 있는 것 정리**: 8080번을 쓰는 서버, 이전에 켠 작업자·예약 작업이 남아 있으면 먼저 끕니다.
   특히 **예약 작업이 두 개 돌면 쿠팡 주문 확인이 두 번씩 실행**되므로 반드시 하나만 돌게 합니다.
4. **최신 코드 받기**: `git pull`. 실패해도 멈추지 말고 "최신 코드를 받지 못했습니다. 지금 있는 코드로 켭니다"라고 알리고 계속합니다.
5. **데이터베이스 표 갱신**: `alembic upgrade head`. 실패하면 오류 내용을 보여 주고 **멈춥니다** (이 상태로 켜면 화면이 제대로 안 나옴).
6. **세 프로그램을 각각 새 PowerShell 창으로 켜기**: 창 제목을 `보탬 서버`, `보탬 작업자`, `보탬 예약작업`으로 붙이고, 창이 저절로 닫히지 않게 (`-NoExit`) 합니다. 각 창은 backend 폴더로 이동하고 가상환경을 켠 뒤 명령을 실행합니다.
7. **확인 후 브라우저 열기**: `http://localhost:8080/health`가 정상 응답할 때까지 최대 1분 기다린 뒤 `http://localhost:8080/agri.html`을 엽니다.
8. 끝나면 "다 켜졌습니다. 창 3개는 닫지 마세요. 끌 때는 바탕화면의 [보탬 끄기]를 누르세요."라고 보여 줍니다.

어느 단계든 실패하면 무엇이 안 됐는지 쉬운 한국어로 보여 주고, 창이 바로 닫히지 않게 "아무 키나 누르면 닫힙니다"로 기다립니다.

### 3. 끄기 스크립트 `backend\scripts\stop_all.ps1` 만들기
- 서버(8080번), 작업자, 예약 작업 프로세스와 그 창들을 끕니다.
- **도커의 데이터베이스는 끄거나 지우지 않습니다.** (`docker compose down -v` 같은 데이터를 지우는 명령은 절대 쓰지 않음)

### 4. 더블클릭용 파일과 바탕화면 아이콘
- `backend\scripts\보탬_켜기.bat`, `backend\scripts\보탬_끄기.bat`를 만듭니다.
  내용은 `powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0start_all.ps1"` 형태 (끄기는 stop_all.ps1).
- 대표님 바탕화면에 `보탬 켜기`, `보탬 끄기` 바로가기를 만듭니다. 바탕화면 위치는 OneDrive 바탕화면일 수 있으니 실제 위치를 확인하세요.

### 5. 한글 깨짐 방지
- 윈도우 기본 PowerShell(5.1)은 BOM 없는 UTF-8 파일의 한글을 깨뜨립니다. `.ps1` 파일은 **UTF-8(BOM 포함)**으로 저장하세요.
- `.bat` 파일 안의 한글 경로·글자도 깨지지 않는지 실제로 실행해서 확인하세요 (필요하면 `chcp 65001`).

### 6. 실제로 켜서 확인
- 켜기 스크립트를 한 번 실행하고 아래를 모두 확인합니다.
  - `http://localhost:8080/health` 정상
  - `http://localhost:8080/agri.html` 열림 (200)
  - 작업자 창, 예약 작업 창에 빨간 오류가 없음
- 끄기 스크립트를 실행해서 셋 다 꺼지는지, 다시 켜기를 했을 때 예약 작업이 하나만 도는지 확인합니다.
- 문제가 있으면 고친 뒤 다시 확인합니다.

### 7. 저장하고 올리기
- `backend\scripts\` 안의 새 파일만 커밋하고 `claude/amazing-cannon-fjkoca` 브랜치에 올립니다 (`git push origin claude/amazing-cannon-fjkoca`).
- `.env` 같은 비밀번호·연동 키 파일은 절대 커밋하지 않습니다. 바탕화면 바로가기도 커밋하지 않습니다.

### 8. (물어보고 결정) 노트북을 켜면 저절로 켜지게
이 노트북은 판매용으로 계속 켜 둘 예정입니다. 윈도우에 로그인하면 `보탬 켜기`가 저절로 실행되도록 시작 프로그램에 등록할지 **대표님께 물어보고**, 원하시면 등록합니다.

## 지켜야 할 것
- 데이터베이스 자료를 지우는 명령은 쓰지 않습니다.
- `.env`의 비밀번호·연동 키 값을 화면에 보여 주거나 바꾸지 않습니다.
- 판매 프로그램 코드(`app` 폴더)는 켜는 데 꼭 필요한 경우가 아니면 고치지 않습니다. 고쳐야 하면 먼저 이유를 설명합니다.
- 마지막 보고는 "무엇을 만들었고, 앞으로 대표님은 무엇만 누르면 되는지"를 3~5줄로 쉽게 정리합니다.
