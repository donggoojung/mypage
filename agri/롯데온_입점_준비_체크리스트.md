# 롯데온 입점 준비 체크리스트

작성: 2026-11-05. 롯데온 판매자센터: https://store.lotteon.com
※ 표시는 인터넷 글을 참고한 것이라 **판매자센터 안내로 다시 확인**해야 하는 내용입니다.

## 1. 입점 신청 전에 (대표님)

- [ ] 사업자등록에 **농산물 소매(면세) 업종**이 있는지 확인 — 없으면 홈택스나 세무서에서 추가
- [ ] 통신판매업 신고증의 취급품목에 **식품**이 들어 있는지 확인 — 관할 시·군·구청
- [ ] 입점 서류를 스캔해 두기 ※
  - 사업자등록증
  - 통신판매업 신고증
  - 통장 사본 (정산받을 계좌)
  - 인감증명서 또는 본인서명사실확인서
  - 대표자 신분증 사본
- [ ] 판매자센터에서 `입점 신청 → 서류 등록 → 최종 승인` 진행 (승인까지 영업일 1~2일 정도 ※)

## 2. 입점 신청하면서 롯데온에 물어볼 것 (1:1 문의 또는 입점 상담)

시스템 설계에 영향을 주는 질문입니다. 답을 받으면 이 파일에 적어 두세요.

1. **식품(과일·채소·쌀·잡곡) 카테고리를 팔려면 추가 서류나 별도 승인이 필요한가요?** (식품 영업 신고, 농산물 관련 서류 등)
2. **공급사가 고객에게 직접 보내는 방식(위탁·업체배송)도 일반 셀러가 할 수 있나요?** 상품 설명이나 표시에 지켜야 할 것이 있나요?
3. **농산물(과일, 채소, 쌀, 잡곡)의 판매수수료율**은 얼마인가요? 신규 입점 수수료 면제나 할인 행사가 있나요?
4. 일반 상품은 **발송 예정일을 최대 3일**까지만 잡을 수 있다고 하는데, 신선식품은 예외가 있나요? 산지 출고가 3일을 넘는 품목은 어떻게 하나요?
5. 신선식품 **취소·반품 규정** (단순변심 반품 제한 등)을 상품 화면에 어떻게 표시하나요?
6. 오픈 API로 상품을 올리면 **롯데온 상품 승인(검수)** 을 거치나요? 얼마나 걸리나요?

## 3. 입점 승인 직후 판매자센터에서 (대표님, 제가 화면 보면서 안내 가능)

- [ ] **출고지·반품지 등록**: 공급사가 보내는 곳(출고지)과 반품 받을 곳(반품지)
  - 공급사가 여러 곳이면 출고지도 공급사별로 필요할 수 있음 → 공급사 주소 자료가 필요
  - 반품은 공급사로 받을지, 사무실로 받을지 결정
- [ ] **배송비 정책 등록**: 무료배송으로 시작하는 것을 추천 (가격에 택배비가 이미 들어 있음). 제주·도서산간 추가 배송비도 정하기
  - 새로 만든 배송비 정책은 약 5분 뒤부터 쓸 수 있음
- [ ] **택배사 확인**: 공급사가 쓰는 택배사 이름 (송장 입력 때 필요)
- [ ] **고객센터 전화번호** 등록
- [ ] **OpenAPI 관리 → 서버 IP 등록 → 인증키 발급** (아래 4번)

## 4. 자동 연동을 켜기 위한 준비 (대표님)

- [ ] **사무실 인터넷의 고정 IP 확인**: 통신사 고객센터에 "고정(공인) IP인지" 문의. 유동 IP면 고정 IP 신청 또는 고정 IP 서버 사용 필요
  - 롯데온은 **등록한 IP에서 호출할 때만** 허용합니다 (아니면 403 오류)
- [ ] 인증키 발급 후 알려 주기 (채팅에 붙여넣지 말고 `backend/.env` 파일에 직접 넣는 방법을 안내해 드립니다)
  - 인증키는 **1년마다 다시 발급**해야 하고, 한 번에 3개까지 만들 수 있습니다

## 5. 대표님이 정해 두면 좋은 것

- [ ] 첫 공급사와 첫 상품 3~5개 (롯데온에 먼저 올릴 것)
- [ ] 출고지·반품지 주소
- [ ] 반품 택배비를 누가 부담할지 (신선식품은 상품 문제일 때만 판매자 부담이 일반적)
- [ ] 쌀·잡곡·채소의 최소 이익 금액 (과일은 4,000원으로 확정)

## 6. 제가 지금 미리 해 두는 것 (입점 전에 가능한 것)

- 롯데온 연동 코드를 **연습 모드**로 만들기: 상품 등록 → 주문 가져오기 → 송장 입력 → 취소·반품 승인
- 등록 전 점검 (원산지, 생산자, 사진, 카테고리 번호, 출고지·배송비정책 번호 등이 비었는지 확인)
- 설정 화면에 롯데온 칸 만들기 (출고지번호, 반품지번호, 배송비정책번호, 카테고리 번호)
- 롯데온 API 설명서를 `agri/롯데온_설명서/` 폴더에 정리
- 쌀 표시 항목(품종, 생산연도, 도정일자 등)과 식품 상품고시 맞추기

## 7. 인증키를 받은 뒤 순서 (제가 하는 일)

1. `.env`에 인증키를 넣고, 롯데온 `Identity` 확인 호출로 **연결 성공**을 확인
2. 롯데온 표준카테고리·전시카테고리 번호를 조회해서 설정 화면에 입력
3. 출고지·반품지·배송비정책 번호를 조회해서 설정 화면에 입력
4. 상품 **1건**을 실제로 등록 → 롯데온 승인 상태 확인 → 판매자센터에서 화면 확인
5. 첫 주문이 들어오면 주문 가져오기 → 발주 → 송장 입력 흐름을 **1건씩** 직접 확인
