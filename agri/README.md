# 농산물 위탁판매 프로젝트

공급사(산지·도매)가 고객에게 직접 보내는 농산물을 오픈마켓에서 파는 사업입니다.
재고를 미리 사두지 않고, 주문이 들어오면 공급사에 발주합니다.

- 기획안: https://claude.ai/artifact/1mgmSW66TL4oLLUCGqRR5K
- 판매 프로그램 코드는 신발 때 만든 `backend/`를 같이 씁니다 (주문 감지, 고객문의, 정산, 쿠팡 연동 재사용).
  이 폴더에는 농산물 사업의 결정 사항, 작업 순서, 공급사 자료를 모읍니다.

## 확정된 결정 (2026-11-05)

| 항목 | 결정 |
| --- | --- |
| 첫 마켓 | 네이버 스마트스토어 (입점이 가장 쉽고 수수료가 가장 낮음) |
| 확장 마켓 | 쿠팡 → 토스쇼핑 → 11번가 → G마켓·옥션, 4곳 모두 진행 |
| 상품 공급 | 농산물 위탁 공급사 (주력 공급사는 대표님이 정해서 전달) |
| 과일 마진 | 건당 최소 이익 4,000원 |

## 대표님 확인이 필요한 것

- [ ] 주력 공급사 자료 전달 → `suppliers/` 폴더 설명 참고
- [ ] 과일 외 품목(채소, 쌀, 잡곡)의 최소 이익 금액
- [ ] 사업자등록에 농산물 소매(면세) 업종 추가 — 세무서 또는 홈택스
- [ ] 통신판매업 신고증의 취급품목에 식품이 들어 있는지 확인 — 관할 시·군·구청
- [ ] 스마트스토어 판매자 가입

## 작업 순서

진행 상황은 `[x]`로 표시합니다.

### 0단계 준비 (대표님)
- [ ] 위 "확인이 필요한 것" 처리
- [ ] 공급사 2~3곳 상담, 계약 전 체크리스트 확인 (기획안 "농산물 위탁 공급사" 참고)

### 1단계 손으로 팔아보기 (대표님 + 클로드 안내)
- [ ] 공급사 상품 3~5개를 스마트스토어에 직접 등록
- [ ] 첫 주문을 공급사 방식(엑셀 등)으로 발주하고 송장 입력
- [ ] 주문 5건 배송 완료, 클레임 처리까지 한 번 경험

### 2단계 시스템 개편 (클로드)
- [ ] 2-1 농산물 마진 계산 (과일 최소 4,000원, 마켓별 수수료)
- [ ] 2-2 상품 구조 일반화: 신발 사이즈 대신 중량·수량·등급 옵션
- [ ] 2-3 공급사 상품 가져오기 (공급사 엑셀 또는 자동 연동)
- [ ] 2-4 농산물 상품정보고시, 원산지·양곡 표시, 청약철회 제한 안내 문구
- [ ] 2-5 스마트스토어 자동 연동: 상품 등록
- [ ] 2-6 스마트스토어 자동 연동: 주문 조회, 발송(송장) 처리, 취소·반품
- [ ] 2-7 공급사 발주서 자동 생성, 송장 받아서 마켓에 입력

### 3단계 자동 운영 (대표님 + 클로드)
- [ ] 상품 20~30개로 확대
- [ ] 품절·가격 변경 자동 반영
- [ ] 고객문의 자동 답변을 농산물용(신선도, 배송, 보관)으로 조정
- [ ] 2주 동안 손으로 고칠 일 없이 운영

### 4단계 마켓 확장 (클로드)
- [ ] 쿠팡 (기존 연동 재사용, 농산물 카테고리로 조정)
- [ ] 토스쇼핑
- [ ] 11번가
- [ ] G마켓·옥션

## 판매 전에 알아둘 법적 표시

- **원산지 표시**: 농산물은 원산지 표시가 법적 의무입니다.
- **쌀(현미 포함)**: 품목, 중량, 생산자, 원산지, 품종, 생산연도, 도정일자, 등급을 표시해야 합니다.
  거짓 표시는 형사처벌, 미표시는 과태료 대상입니다.
- **신선식품 단순변심 반품 제한**: 상세페이지에 미리 알려야 효력이 있습니다.
