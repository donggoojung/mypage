# 롯데온 자동 연동 메모 (2026-11-05 조사)

롯데온에 올리는 작업은 공식 설명서를 보고 만든다. 설명서는 로그인 없이 읽을 수 있다: https://api.lotteon.com
(JavaScript로 그려지는 사이트라 단순 웹 검색·내려받기로는 내용이 안 읽힌다. 브라우저로 열어야 한다.)

## 연동 조건 (설명서의 "시작하기" 기준)

- 호출 주소: `https://openapi.lotteon.com` (HTTPS, 방식은 GET/POST만, JSON)
- 인증: 판매자센터에서 발급한 **인증키**를 헤더 `Authorization: Bearer 인증키`로 보낸다. (스마트스토어처럼 서명을 만들 필요 없음)
  - 같이 보내는 헤더: `Accept: application/json`, `Accept-Language: ko`, `X-Timezone: GMT+09:00`, POST는 `Content-Type: application/json`
- **서버 IP 등록 필수**: 판매자센터 → 판매자정보 → OpenAPI관리 → 정보설정에서 호출할 서버의 IP를 등록해야 키를 발급할 수 있다. 등록 안 한 IP에서 부르면 403. (사무실 인터넷이 고정 IP여야 한다 → 2-8과 같은 문제)
- 인증키는 **유효기간 1년**, 만료 전에 재발급. 한 번에 최대 3개까지 발급 가능(교체용).
- 호출 한도: 키당 분당 10,000회 (넘으면 429).
- 접속 확인용 API: `GET /v1/openapi/common/v1/identity` (성공이면 `{"returnCode":"SUCCESS", ...}`)
- 판매자센터는 **입점이 끝난 뒤에** 쓸 수 있다.

## 상품 등록 설명서에서 확인한 것 (농산물에 중요한 것만)

- 필수: 거래처그룹코드·거래처번호(`trGrpCd`, `trNo`), 표준카테고리(`scatNo`), 전시카테고리(`dcatLst`: 몰구분 `LTON` + 말단 카테고리 번호), 판매자상품명(`spdNm`, 150자), **원산지코드**(`oplcCd`, 공통코드 `OPLC_CD`), 상품고시(`pdItmsArtlLst`: 항목코드+내용), 구매가능수량정보, 연령제한(`ageLmtCd`, 0=전연령), 선물포장/메시지 가능 여부, 상품상태(`pdStatCd`=`NEW`), 배송처리유형(`dvProcTypCd`=`LO_ENTP` 업체배송), 배송상품유형(`dvPdTypCd`=`GNRL`), 배송수단(`dvMnsCd`=`DPCL` 택배), **출고지번호**(`owhpNo`), **배송비정책번호**(`dvCstPolNo`), **회수지번호**(`rtrpNo`), 재고관리 여부(`stkMgtYn`), 단품 여부(`sitmYn`, Y면 옵션 목록 필요)
- 보관 방법: `saveTypCd` = `RFRG` 냉장 / `FRZN` 냉동 / `FRSH` 신선 / `NONE`
- **일반상품의 최대 발송예정일수는 3일** (`dvPdTypCd`=`GNRL`). 공급사 출고가 3일을 넘기는 품목은 올리기 전에 확인해야 한다.
- 출고지·반품지·배송비정책은 먼저 등록해 두어야 한다 (판매자센터에서 직접 하거나 API로). 새 배송비정책은 등록 뒤 약 5분 지나야 상품 등록에 쓸 수 있다.
- 상품 설명 HTML 안의 이미지 주소에 `doc-pub.lotteon.com/ec/public` 경로를 쓰면 나중에 이미지가 사라질 수 있으니 쓰지 않는다.
- 아직 안 읽은 부분: 단품(옵션) 목록 필드, 이미지 필드, 가격·재고 필드, 응답 형식, 식품 상품고시 항목 코드

## 대표님이 해야 하는 준비 (코드로 대신할 수 없음)

1. 롯데온 판매자 입점 (농산물·식품 카테고리를 팔 수 있는지, 입점 서류 확인)
2. 판매자센터에서 출고지·반품지, 배송비정책 만들기 (또는 API로 등록)
3. 사무실 인터넷의 고정 IP 확인 후 OpenAPI관리에 등록 → 인증키 발급
4. 인증키를 `backend/.env`에 넣기 (코드에는 넣지 않음)
