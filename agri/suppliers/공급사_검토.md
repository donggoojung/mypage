## 고르는 기준

1. **발주를 자동으로 넣을 수 있는가**: 엑셀 양식이 정해져 있거나 자동 연동이 되면 우리 프로그램이 대신 처리할 수 있습니다. 카카오톡 발주는 사람이 해야 합니다.
2. **과일 최소 이익 4,000원이 남는가**: 공급가에 택배비가 포함인지 먼저 확인합니다.
3. **상한 과일 보상**: 클레임이 나면 누가 비용을 내는지
4. **당일 출고 마감 시간**

## 전화로 물어볼 것

- [ ] 가입비, 월회비, 예치금(선입금)이 있는지
- [ ] 공급가에 택배비 포함 여부, 제주·도서산간 추가 배송비
- [ ] 발주 방법: 엑셀 양식, 자동 연동, 카카오톡 중 무엇인지 (엑셀 양식 파일 받기)
- [ ] 송장번호를 언제, 어떤 방식으로 주는지
- [ ] 당일 출고 마감 시간
- [ ] 상함·파손 보상 기준 (사진 제출 기한, 재발송·환불 부담)
- [ ] 상품 사진·상세페이지를 우리 마켓에 써도 되는지
- [ ] 원산지, 생산자, 중량, 등급 정보 제공 여부
- [ ] 품절·가격 변경 알림 방법
- [ ] 세금계산서(면세 농산물은 계산서) 발행 여부와 정산 주기
