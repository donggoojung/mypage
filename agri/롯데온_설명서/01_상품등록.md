# 01. 상품 등록 (롯데온 API 센터 기준, 읽은 날짜 2026-11-05)

출처: https://api.lotteon.com/apiService/?menuIdx=4&apiNo=87&apiMjrVerCd=V1&apiMnrVerNm=1.0
표기: 필수 O = 필수, △ = 조건부 필수, 빈칸 = 선택, X = 설명서가 X로 표기(rtrvTypCd 한 곳, 아래 참고).
※ 해석: 설명서 본문은 들여쓰기가 없어 중첩 구조는 "요청 예시 JSON"과 설명 문구로 판단했다.

## 1. 기본 정보
- 이름: 상품 등록 (설명: "상품을 생성한다. 상품은 한개 이상의 아이템으로 구성된다.")
- 방식/주소: `POST https://openapi.lotteon.com/v1/openapi/product/v1/product/registration/request`
- 요청 최상위: `{"spdLst": [ {상품}, {상품} ... ]}` (배열. 한 번에 여러 상품 가능; 최대 개수는 설명서에 없음)
- 일반 셀러: trGrpCd = `SR` (설명서의 다른 API들에 "일반셀러 : SR"이라고 적혀 있음. 이 페이지 예시도 "SR")

## 4. 원산지코드 (oplcCd)
- 설명서에는 값 목록이 **없음**. "[공통코드 : OPLC_CD]" 라고만 적혀 있고, 기타는 "상품상세 참조" 코드를 입력하라고만 함.

## 6. 상태·오류 코드 (이 페이지 표)
- HTTP: 200 정상(정상처리, 체크에서 에러값은 리턴코드로 출력) / 401 등록되지 않은 OpenAPI Key / 404 비정상 Request 호출·페이지 없음 / 429 호출 가능 횟수 초과, 00분 후 다시 호출 / 403 접근이 거부 / 500 시스템 오류
- returnCode: 0000 정상 처리되었습니다. / 9999 SYSTEM ERROR
- resultCode: 0000 정상 / 9999 SYSTEM ERROR / 1001 체크공통 "[해당항목]은 필수입력입니다." / 1002 "[해당항목]의 DATA형식이 잘못 되었습니다." / 1003 "[해당항목]의 공통코드가 잘못 되었습니다." / 2001 업무영역 "ex) 종료일이 시작일 보다 이전 날짜일 수 없습니다."

## 8. 사용상 주의 (설명서에서 읽은 것)
- 발송예정일 상한: GNRL(일반상품) 최대 3일, OD_MFG(주문제작) 15일. sndBgtNday를 0(오늘발송)으로 하면 평일 발송마감시간(nldySndCloseTm) 필수 적용.
- 옵션 상품(sitmYn=Y)은 itmLst[].itmOptLst 필수, 옵션 없는 상품(sitmYn=N)은 itmOptLst 생략하고 단품 1개만 보냄.
- 재고관리(stkMgtYn) N이면 재고 999,999,999로 고정 → 재고 API 필요 없음. Y면 stkQty 필수.
- 배송비정책/추가배송비정책은 신규 등록 후 약 5분 뒤에 상품에 연결해야 함.
- 이미지: 단품당 1~10개, jpg/jpeg/png, 접근 가능한 전체 URL. 정사각형(IMG_SQRE) 또는 세로형(IMG_LNTH). 규격(픽셀 크기·용량)은 설명서에 없음.
- 승인: 등록 후 카테고리·상품정보 승인 절차가 있음 (승인상태 필드는 02번 파일의 상세조회/목록/승인이력 API 참고). 등록 응답 자체에는 승인 결과가 없음.
- 같은 epdNo로 재등록 시 동작(중복 방지)은 설명서에 없음.
