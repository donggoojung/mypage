# 07. 반품 · 교환 (롯데온 API 센터 기준, 읽은 날짜 2026-11-05)

공통: `https://openapi.lotteon.com` + POST + JSON. HTTP 오류 표 공통(200/401/404/429/403/500).

## 가장 중요한 변경점 (설명서 문구)
- **반품·교환 "요청" 단계는 2022년 6월 28일부로 제거됨.** 그래서 **반품요청 승인/거부, 교환요청 승인/거부 API 4개(52, 53, 71, 72)는 2022년 6월 28일에 종료**되었다. (설명서 제목에 "(2022년 6월 28일 종료)" 표기, 본문에 "교환/반품 요청 단계 생략됨에 따라 교환/반품 승인/거부 API는 2022년 6월 28일에 종료 되었습니다.")
- 반품/교환 목록 조회 API(51, 69)는 **"참조 목적"**이며, 실제 업무 처리(회수지시, 출고 등)는 배송 모듈의 **"출고/회수지시(주문정보) 조회" API(05번 파일 A)** 를 사용하라고 설명서가 명시.
- 반품/교환 접수 후 **회수지시는 접수 30분 뒤** 변경되며, 그때부터 출고/회수지시 API로 조회 가능.
- ※ 해석: 즉 반품·교환은 "셀러가 승인한다"가 아니라, 고객이 접수하면 곧바로 접수(03) → 회수지시(odPrgsStepCd 23)로 내려오고, 셀러는 (1) 회수지시 조회 → (2) 연동완료 통보(05번 B) → (3) 회수진행/회수완료/회수확정을 배송상태 통보(05번 C, 24/25/26)로 알리는 구조. 반품 거부/보류에 쓰는 API는 이 설명서 범위에 없음.

## A. 반품요청/접수 목록조회 (apiNo 51) — 참조용

| srchEndDttm | O | String | 20 | 검색종료일자 |

| odSeq | | Number | 3 | 주문순번 |

- returnCode: 0000 / 2001·2002 기간조회 시작·종료일 필수 / 2004 30일 초과 / 2005 / 3000 조회내역이 없습니다 / 3001 주문번호가 존재하지 않습니다 / 9000~9002
- 요청 예시(설명서 그대로, 쉼표 누락 오류 있음): `{"srchStrtDttm":"20191022","srchEndDttm":"20191022" "odNo":"201910221000001" "trNo":"LE10002",}`
- 응답 예시: 따옴표 없는 의사 JSON, `data:[{odNo:..., cmNo:..., itemList:[{odSeq:1, procSeq:2, .....}]}]` (clmNo를 cmNo로 표기)
- 책임(귀책) 구분은 이 API 응답에는 없음: 배송비 부담주체(dvCstBdnMnbdCd)만 있고, "출고/회수지시 조회"(05번 A)에 `imptDvsCd`(01 고객 / 02 당사)가 있음.
- 농산물 관련: 반품 가능 기간·신선식품 반품 제한 같은 정책 문구는 이 설명서에 없음 (상품 등록의 rtngPsbYn, xchgPsbYn으로 반품·교환 가능 여부만 설정).
