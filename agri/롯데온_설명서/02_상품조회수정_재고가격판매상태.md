# 02. 상품 조회·수정·재고·가격·판매상태 (롯데온 API 센터 기준, 읽은 날짜 2026-11-05)

공통: 모두 `https://openapi.lotteon.com` 아래, 별도 표시 없으면 POST + JSON. 일반셀러 trGrpCd = `SR`.
공통 오류 표(HTTP/returnCode/resultCode)는 01번 파일 6절과 같음 (429 문구 "호출 가능 횟수 초과, 00분 후 다시 호출해주세요").
※ 해석: 이 설명서는 목록/수정 요청에서 "일반셀러 SR" 문구를 trGrpCd 설명 칸에 적어 둠.

## C. 승인 상품 수정 (apiNo 90)
- `POST https://openapi.lotteon.com/v1/openapi/product/v1/product/modification/request`
- 설명: "승인된 상품의 정보를 수정한다."
- 요청 최상위 `{"spdLst":[ ... ]}`. 구조는 등록(01번 파일)과 같고 아래만 다르다.
  - **spdNo (O, string 30, 판매자상품번호)**가 필수이며 어떤 상품을 수정할지 가리킨다. trGrpCd/trNo는 예시에 포함(예시 "SR", "(거래처번호)").
  - 거의 모든 필드가 선택(필수 표시 없음): 바꿀 것만 보낸다고 읽힘. ※ 해석: 설명서에 "보낸 것만 수정"이라는 명시 문구는 없고, 예시가 전체 필드를 보냄.
  - tdfDvsCd 설명이 "과면세구분코드"로 표기됨 (코드 값은 01 과세/02 면세/03 영세/04 해당없음과 동일).
  - `itypOptDelYn`(string 1, 입력형옵션삭제여부) 추가.
  - `pdFileLst`: "pdFileLst = [] 일 경우 상품콘텐츠파일목록 삭제".
  - `stkMgtYn`: 재고관리여부 [Y,N] — "Y->N 수정만 가능하다. N->Y 수정은 불가하다." (마트·슈퍼는 점포별 관리 API)
  - 단품 `itmLst[]`:
    - `sitmNo` (string 30, 판매자단품번호): 기존 단품 수정 시 입력.
    - 예시 주석: "(sitmNo 입력, itmOptLst 미입력) 기존 단품 수정. (sitmNo 미입력, itmOptLst 입력) 단품 추가."
    - `itmOptLst`는 "단품추가시에만 사용하는 항목". "기존 등록된 단품의 옵션,옵션값은 수정이 불가하다." optCd는 기존 단품의 옵션명에 해당하는 옵션코드(이관 상품의 옵션코드가 null인 경우에만 null 허용), optNm은 "기존에 등록된 단품의 옵션명만 입력가능".
    - `itmImgLst[].origImgFileNm`: "기존에 등록된 URL과 동일하지만 이미지만 변경되었을 경우 URL이 변경되어야 정상 반영된다. URL 뒤에 쿼리스트링을 추가하거나(예 `http://abc.com/12/34/56/78_90.jpg?t=20220316`) 경로 자체를 바꿔야 한다."
    - slPrc, stkQty, sortSeq 등도 단품 안에서 수정 가능 항목으로 나열됨.
  - 추가상품: adtnPdYn, adtnPdInfo{sortCd, adtnTypeLst[]{adtnTypNo(O), adtnTypNm, delYn, adtnPdLst[]{adtnPdNo(O), adtnPdNm, slPrc, stkQty, useYn, delYn}}} (우리 용도 아님 → 생략: 해당 없음)
  - 생략: 해당 없음 — 엘롯데·마트·슈퍼·하이마트·렌탈·개통형·스마트픽·e쿠폰 관련 필드 전부
- 응답: returnCode(O), message(O), data[]{epdNo, spdNo(O), resultCode(O), resultMessage(O)}
- 요청 예시: 01번 예시와 거의 같은 전체 JSON + `"spdNo":"LO13xxxx"`, itmLst 2개(첫 번째는 `sitmNo:"LO13xxxx_1370590"`과 itmImgLst만, 두 번째는 `eitmNo:"ITM_2"`, `sortSeq:2`, `itmOptLst:[{optNm:"색상",optVal:"핑크"}]`, `slPrc:200000`, `stkQty:110`의 신규 단품). 응답 예시 `{"returnCode":"0000","message":"정상 처리되었습니다"}`.
- 주의: 승인된 상품 기준 API다. 가격/재고만 바꿀 때는 아래 D/E의 전용 API가 따로 있음.

## D. 재고 API (apiNo 86)

- 요청 `{"itmStkLst":[...]}`
| 항목 | 필수 | 타입 | 길이 | 설명 |
|---|---|---|---|---|
| trGrpCd | O | String | 11 | 일반셀러: SR |
| trNo | O | String | 11 | 거래처번호 |
| lrtrNo | | String | 11 | 하위거래처번호 |
| spdNo | O | String | 30 | 판매자상품번호 |
| sitmNo | O | String | 30 | 판매자단품번호 |
| stkQty | O | number | 10 | 단품재고 |
- 응답: returnCode, message, subMessages(null), dataCount, data[]{spdNo, sitmNo, lrtrNo, resultCode, resultMessage}. 성공 시 resultCode "0000", resultMessage "정상 처리되었습니다."
- 요청 예시:
```json
{"itmStkLst":[{"spdNo":"LMTLM20200221","sitmNo":"LMTLM20200221_001","trGrpCd":"LM","trNo":"LM000000","lrtrNo":"SLM102","stkQty":150},{"spdNo":"LMTLM20200221","sitmNo":"LMTLM20200221_001","trGrpCd":"LM","trNo":"LM000000","lrtrNo":"SLM103","stkQty":150}]}
```

- 주의: 절대값(stkQty)으로 덮어쓰기. 한 번에 보낼 수 있는 건수 제한은 설명서에 없음. 재고관리여부(stkMgtYn)가 N인 상품은 재고가 999,999,999 고정(01번 파일).

## H. 승인상태변경이력 조회 (apiNo 95)
- `POST https://openapi.lotteon.com/v1/openapi/product/v1/product/approve/history/list`
- 요청
| 항목 | 필수 | 타입 | 길이 | 설명 |
|---|---|---|---|---|
| trGrpCd | O | String | 11 | |
| trNo | O | String | 11 | |
| lrtrNo | | String | 11 | |
| spdNo | O | String | 30 | 판매자상품번호 |
| hstStrtDttm | O | String | 14 | 이력시작일시 YYYYMMDDHH24MISS |
| hstEndDttm | O | String | 14 | 이력종료일시 |
- 응답 data[] (array): spdNo, spdNm(100), pdNm(전시상품명, 30), pdAprvReqCd, pdAprvReqGvbkRsnCd, catAprvStatCd, catGvbkRsnCd, catGvbkRsnCnts(4000), pdInfoAprvStatCd, pdInfoGvbkRsnCd, pdInfoGvbkRsnCnts(4000), fnlAprvYn, modrDttm(수정일시)
  - 코드값은 목록조회(A)와 같음: pdAprvReqCd = APRV_REQ/APRV_CMPT/GVBK/PD_REG/NONE, catAprvStatCd = APRV_WT/APRV_CMPT/GVBK/ADMR_TCTL/NONE, pdInfoAprvStatCd = APRV_WT/APRV_CMPT/GVBK/NONE
- 요청 예시: `{"trGrpCd":"LM","trNo":"LM000000","lrtrNo":null,"spdNo":"LM12345678","hstStrtDttm":"20200303111111","hstEndDttm":"20200303111111"}`
- ※ 해석: 반려(GVBK) 사유는 사유코드/사유내용(catGvbkRsnCnts, pdInfoGvbkRsnCnts)으로 확인한다. 반려 사유 코드표는 이 설명서에 없음.
