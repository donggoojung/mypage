# 03. 카테고리 · 속성 · 브랜드 조회 (롯데온 API 센터 기준, 읽은 날짜 2026-11-05)

## 공통 사항 (4개 API 모두)
- 호출 주소가 다른 서버다: `https://onpick-api.lotteon.com/cheetah/econCheetah.ecn?job=<작업명>` (`GET`). 상품 API 서버(`openapi.lotteon.com`)와 다름.
- 설명서에는 이 서버의 인증 헤더를 따로 설명하지 않음("설명서에 없음"). ※ 해석: 시작하기 문서의 Bearer 인증키 방식이 같은지는 설명서만으로 확인 불가 — 실제 호출해 봐야 함.
- 요청은 쿼리스트링 파라미터. 필수 `job`. 나머지는 전부 선택(X).
- 공통 조회 파라미터: `skip`(int, 기본 0), `limit`(int, 기본 100), `between_start_1`/`between_end_1`(long, 수정일 범위 YYYYMMDDHHMMSS), `sort`(정렬 필드: sort_1 = 수정일 / sort_2 = 각 ID), `direction`(asc / desc).
- 응답 형태(예시 기준): `{"itemList":[ { "id":..., "key":..., "data":{...실제 내용...}, "filter_1":..., "filter_2":..., "filter_3":..., "mod_date":..., "is_delete":false, "sort_1":..., "sort_2":..., "between_start_1":..., "between_end_1":... } ]}`. 실제 항목은 `data` 안에 있음. (설명서의 "Received Message" 표는 data 안 필드 목록.)
- 상태 코드: 200 / 400 Bad Request / 401 등록되지 않은 OpenAPI Key / 404 / 403 / 500. (429 행은 이 4개 문서에 없음)
- 페이지네이션: `skip`+`limit`. 총 개수 필드는 설명서에 없음. ※ 해석: 결과가 limit보다 적게 올 때까지 skip을 늘려 반복.
- ※ 해석: `is_delete`가 true인 항목은 삭제된 것으로 보이나 설명서에 설명 없음. `use_yn`이 Y인 것만 쓰는 것이 안전.

## C. 속성 기본 조회 (apiNo 203)
- `GET https://onpick-api.lotteon.com/cheetah/econCheetah.ecn?job=cheetahAttr`
- 용도: 속성 유형 조회 + 속성값 매핑 조회.
- 요청 파라미터: job(O, `cheetahAttr`), skip, limit, filter_1(속성 ID attr_id), filter_2(속성값 ID attr_val_id), between_start_1, between_end_1, sort(sort_1 = 수정일 / sort_2 = 속성ID), direction
- 응답 `data` 필드
| 항목 | 필수 | 타입 | 길이 | 설명 |
|---|---|---|---|---|
| attr_id | O | int | 11 | 속성유형 ID (= 상품 등록의 optCd) |
| attr_nm | O | String | 255 | 속성유형명 |
| attr_disp_nm | X | String | 255 | 속성유형전시명 |
| attr_pi_type | O | String | 2 | 속성타입코드 — **P**: 상품 등록/수정 시 `scatAttrLst > optCd`에 해당, **I**: 상품 등록/수정 시 `itmOptLst > optCd`에 해당 |
| attr_val_frm_cd | O | String | 2 | 속성값형식구분코드 (코드값 설명은 설명서에 없음; 예시 "02") |
| use_yn | O | String | 1 | 사용여부 |
| mod_date | O | datetime | | 수정일시 |
| attr_val_list | O | list | 200 | 속성값리스트 |
| attr_val_list[].attr_val_id | O | int | 11 | 속성값ID (= 상품 등록의 optValCd) |
| attr_val_list[].attr_val_nm | O | String | 11 | 속성값명 |
| attr_val_list[].attr_val_disp_nm | O | String | 255 | 속성값전시명 |
| attr_val_list[].attr_ref_val1 | X | String | 20 | 속성참조값1 (색상은 색상계열, 사이즈는 상위계열) |
| attr_val_list[].attr_ref_val2 | X | String | 20 | 속성참조값2 (사이즈의 경우 같은 레벨로 묶이는 정보) |
| attr_val_list[].use_yn | O | String | 1 | 사용여부 |
| attr_val_list[].prio_rnk | O | int | 11 | 우선순위 |
- 사용법(※ 해석): 표준카테고리 조회(A)의 `attr_list[].attr_id`로 이 API를 `filter_1=<attr_id>`로 호출해 선택 가능한 값 목록을 받고, 등록 요청에는 optCd=attr_id, optValCd=attr_val_id, optVal=값 이름(attr_val_nm)을 넣는다. attr_pi_type이 P면 `scatAttrLst`에, I면 단품 `itmOptLst`에 사용.
- 필수 속성인지 여부(상품 등록 시 어떤 속성이 반드시 필요한지)는 이 설명서에 필수/선택 표시가 없음("설명서에 없음").

## D. 브랜드 조회 (apiNo 204)
- `GET https://onpick-api.lotteon.com/cheetah/econCheetah.ecn?job=cheetahBrnd`
- 요청 파라미터: job(O, `cheetahBrnd`), skip, limit, filter_1(브랜드 ID brnd_id), mf_1(브랜드 이름 brnd_nm — "중간 일치 제공"), between_start_1, between_end_1, sort(sort_1 = 수정일 / sort_2 = 브랜드ID), direction
- 응답 `data` 필드: brnd_id(O, String 12, 브랜드ID = 상품 등록의 brdNo), brnd_nm(O, 255, 브랜드대표명), brnd_sct_cd(O, 30, 브랜드유형명코드 — "상품연계시: 상품브랜드"), brnd_nm_main_cd(O, 30, 브랜드대표명구분코드), use_yn(O), mod_date(O), brnd_nm_kr(X, 한글명), brnd_nm_en(X, 영문명), brnd_nm_etc1/brnd_nm_etc2(X), brnd_logo_img_url1(X, 로고 이미지 URL), brnd_desc(X), synonym_keyword(X, 브랜드동의어), type_keyword(X, 255, 브랜드오타어목록; 예시 JSON 키는 `typo_keyword`)
- 응답 예시 발췌: `{"itemList":[{"data":{"brnd_sct_cd":"01","use_yn":"Y","brnd_nm_kr":"골프아미","brnd_nm":"골프아미","brnd_nm_en":"golfami","brnd_id":"P134","brnd_nm_main_cd":"01","synonym_keyword":"golfemi|골프에미|골프애미|골푸아미"},"filter_1":"P134","id":"P134","key":"P134","is_delete":false,"sort_1":1581728447000}]}`
- ※ 해석: 브랜드(brdNo)는 상품 등록에서 필수가 아님(선택). 농산물은 브랜드가 없는 경우 생략 가능해 보임. 단 카테고리 일부는 brnd 제어(전시카테고리 B의 ctrl_brnd_list)가 걸릴 수 있음.
