# 10. 상품정보고시 — 농수축산물 (품목코드 `pdItmsCd` = `20`)

읽은 날짜 2026-11-06. 출처: 롯데온 API 센터 상품 등록 설명서가 안내하는 PDF
"23년 1월 상품정보제공고시 개정반영" (파일 이름 `품목현행화_20221109_공유용.pdf`, 롯데온 문서 서버).
PDF의 글자가 컴퓨터로 읽으면 깨져서(한글 빠짐) **쪽 이미지를 눈으로 읽어** 옮겼다 (8~9쪽).
옆에 있는 "기존 대비 신규 품목고시 변경 부분" PDF는 변경분 목록이라 읽지 않았다.

상품 등록 요청의 `pdItmsInfo.pdItmsArtlLst[]`에 `{"pdArtlCd": 항목코드, "pdArtlCnts": 내용}` 으로 넣는다.
PDF의 마지막 열이 전부 `Y`(필수로 보임)라서 12개를 모두 보낸다. (※ 해석: `Y`가 필수를 뜻한다고 보았다. 설명서에 열 이름은 없었다.)

|---|---|---|---|
| 1460 | 1. 품목 또는 명칭 | 상품명 (`name`) | |
| 0570 | 2. 포장단위별 내용물의 용량(중량), 수량, 크기 | 옵션 이름들 (`weight`) | |

| 1730 | 4. 「농수산물의 원산지 표시 등에 관한 법률」에 따른 원산지 | 원산지 (`origin`) | |

원재료명·함량 0620, 영양성분 0690, 유전자변형식품 0700, 소비자 안전 주의사항 1490, …). 가공식품을 팔 때 다시 읽는다.

최신 상품정보제공고시 표를 확인하고 설정 화면의 "상품정보고시 항목코드"를 고친다.
