# 09. 상품문의(QnA) (롯데온 API 센터 기준, 읽은 날짜 2026-11-05)

공통: `https://openapi.lotteon.com` + POST + JSON. HTTP 오류 표 공통(200/401/404/429/403/500). returnCode 0000 정상 / 9999 SYSTEM ERROR, resultCode 1001·1002·1003·2001은 01번 파일 6절과 같음.
참고: 이 QnA(상품에 대한 문의)와 별도로 메뉴에 "고객센터" 그룹의 `(일반 Seller용)_판매자 문의목록 조회/상세/답변 등록` 등이 있으나(주문 관련 1:1 문의로 보임 ※ 해석) 이번 범위 밖이라 읽지 않음.

## A. 상품QnA 조회 (apiNo 99)
- `POST https://openapi.lotteon.com/v1/openapi/product/v1/product/qna/list`
- 요청
| 항목 | 필수 | 타입 | 길이 | 설명 |
|---|---|---|---|---|
| trGrpCd | O | string | 11 | 거래처그룹코드 (일반셀러 SR) |
| trNo | O | string | 11 | 거래처번호 |
| lrtrNo | | string | 11 | 하위거래처번호 |
| spdNo | | String | 30 | 판매자상품번호 |
| sitmNo | | String | 30 | 판매자단품번호 |
| regStrDttm | O | String | 14 | 등록일시 조회시작일시 YYYYMMDDHH24MISS (이름이 regStr**D**ttm — regStrtDttm 아님) |
| regEndDttm | O | String | 14 | 등록일시 조회종료일시 |
| qstTypCd | | String | 20 | QnA 유형 [QST_TYP_CD] NULL이면 전체유형: `SZ_CAPA` 사이즈/용량 / `DSGN_CLR` 디자인/색상 / `DP_INFO` 상품정보 / `USE_EPN` 사용설명 / `ETC` 기타 |
| qnaStatCd | | String | 20 | QnA처리상태코드 [QNA_STAT_CD] **NULL이면 미처리건(NPROC)만 조회**: `NPROC` 미처리 / `PROC` 처리완료 / `CC_TCTL` 고객센터이관 / `ALL` 전체 |
| pageNo | O | number | 3 | 페이지 |
| rowsPerPage | O | number | 3 | 페이지당 건수 (MAX 100) |
- 응답: returnCode(O), message(O), dataCount(number), data[] 각 항목: trGrpCd(O), trNo(O), lrtrNo, **pdQnaNo**(O, String 20, 상품QnA번호), qstTypCd(O), qnaStatCd(NULL이면 전체 조회라고 되어 있으나 이는 요청 설명 복사로 보임), spdNo(O), sitmNo(O), qstCnts(O, 1000, 질문내용), regDttm(O, 14, 등록일시). 예시에는 `qstTtl`(질문제목, null)도 있음(표에는 없음).
- 요청 예시: `{"trGrpCd":"LI","trNo":"LI000000","lrtrNo":"","spdNo":"","sitmNo":"","regEndDttm":"20201201000000","regStrDttm":"20191231000000","pageNo":1,"rowsPerPage":100}`
- 응답 예시 한 건: `{"trGrpCd":"LI","trNo":"LI000000","lrtrNo":null,"pdQnaNo":"307","qstTypCd":"ETC","spdNo":"LITLI20200127001","sitmNo":"LITLI20200127001_1","qnaStatCd":"NPROC","qstTtl":null,"qstCnts":"1234567841141","regDttm":"20200205004048"}` (최상위: `"returnCode":"0000","message":"정상 처리되었습니다.","subMessages":null,"dataCount":5,"data":[...]`)
- 조회 기간 최대 길이 제한은 설명서에 없음.

## B. 상품QnA 답변 등록 (apiNo 100)
- `POST https://openapi.lotteon.com/v1/openapi/product/v1/product/qna/reply`
- 요청 `{"ansInfo":[ ... ]}`
| 항목 | 필수 | 타입 | 길이 | 설명 |
|---|---|---|---|---|
| trGrpCd | O | string | 11 | 거래처그룹코드 |
| trNo | O | string | 11 | 거래처번호 |
| lrtrNo | | string | 11 | 하위거래처번호 |
| pdQnaNo | O | String | 20 | 상품QnA번호 (A의 pdQnaNo) |
| spdNo | O | String | 30 | 판매자상품코드 |
| sitmNo | O | String | 30 | 판매자단품코드 |
| ansCnts | O | String | 1000 | 답변내용 |
- 응답: returnCode(O), message(O), data[]{pdQnaNo(O, 30), resultCode(O), resultMessage(O)}. 응답 예시는 `{"returnCode":"0000","message":"정상 처리되었습니다 ...}` 한 줄뿐.
- 요청 예시: `{"ansInfo":[{"trGrpCd":"LB","trNo":"LB000000","lrtrNo":"","pdQnaNo":"42","spdNo":"PL00001","sitmNo":"02000","ansCnts":"질문답변"}]}`
- 주의: 답변 수정·삭제 API는 설명서 목록에 없음. 답변 제한(금칙어 등) 설명도 없음.
