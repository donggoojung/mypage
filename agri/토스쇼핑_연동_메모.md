# 토스쇼핑 자동 연동 메모 (2026-11-06 조사)

출처: 토스쇼핑 파트너스 개발 문서 https://shopping-docs.toss.im (각 페이지 주소 끝에 `.md`를 붙이면 원문이 내려온다).
API 명세는 문서 안에 **OpenAPI 형식으로 그대로** 들어 있어서 항목 이름을 추측하지 않고 옮겼다. 실제 키로 호출해 본 적은 아직 없다.

## 연결 방법

- 운영 주소 `https://shopping-fep.toss.im`, 테스트 주소 `https://shopping-fep-alpha.toss.im`
- 인증키 발급 (대표님이 직접): 토스쇼핑 파트너스 → **상점 이름 → 가맹점·계정 관리 → 자체 개발 → `키 발급`**.
  호출할 **IP 주소를 입력**하고 발급하면 **Access Key**와 **Secret Key**가 나온다. 등록한 IP에서만 호출된다.
- 토큰 발급: `POST https://oauth2.cert.toss.im/token` (테스트: `https://oauth2-alpha.cert.toss.im/token`),
  본문(form) `grant_type=client_credentials`, `client_id=<Access Key>`, `client_secret=<Secret Key>`, `scope=toss-shopping-fep:write`.
  응답 `access_token`, 유효기간 약 1년(`expires_in` 31535999초). **호출마다 토큰을 다시 받지 말 것** (과하면 이용 제한).
- 이후 모든 호출: `Authorization: Bearer <access_token>`, `Content-Type: application/json`
- 한도: 셀러당 API별로 쓰기 초당 30회, 읽기 초당 50회. 클레임 조회는 10~60분 간격 (10분보다 짧게 부르면 이용 제한 가능)
- 응답은 항상 HTTP 200이고 `resultType`이 `SUCCESS`/`FAIL`. 실패면 `error.errorCode`, `error.reason`.
- 테스트 환경은 별도 신청 (Google 폼, outbound IP와 담당자 정보 제출). 공용 테스트 상점이고, 테스트 상품은 검수 통과를 메일로 요청해야 한다.

## 우리가 쓰는 API

| 용도 | 방식 주소 |
|---|---|
| 카테고리 찾기 | `GET /api/v3/shopping-fep/products/categories/children?id=` (`isLeaf=true`가 최하위) |
| 카테고리별 구매옵션 템플릿 | `GET /api/v3/shopping-fep/category/{categoryId}/constraint-templates` |
| 고시 카테고리 코드·항목 | `GET /api/v3/shopping-fep/notices/category-codes`, `GET /api/v3/shopping-fep/notices?categoryCode=` |
| 배송비 묶음 그룹 / 교환반품지 | `GET .../merchants/group-delivery/delivery-location/v2`, `GET .../merchants/group-delivery/exchange-refund-location/v2` |
| 택배사 | `GET /api/v3/shopping-fep/orders/delivery-companies` |
| **상품 등록** | `POST /api/v3/shopping-fep/products/v3` → `success.id` |
| 주문 가져오기 | `GET /api/v3/shopping-fep/orders/v2?startDate=&endDate=&nextCursor=&limit=` (최대 31일, 한 번에 50건) |
| **송장 입력(배송중으로)** | `PUT /api/v3/shopping-fep/orders/products/delivery` `{orderProductId, deliveryCompany(한글 이름), trackingNumber}` |
| **발송 지연** | `PUT /api/v3/shopping-fep/orders/products/status` `{orderProductIds, status:"DELAY_SHIPPING", shippingDeadlineAt, delayReasonType:"READY_PRODUCT"}` |
| 클레임 목록 | `GET /api/v3/shopping-fep/claims?type=CANCEL&status=REQUESTED` |
| **취소 승인** | `POST /api/v3/shopping-fep/claims/{claimId}/cancel/approval` |
| **취소 거절(=이미 출고)** | `POST /api/v3/shopping-fep/claims/{claimId}/cancel/rejection` `{deliveryCompany, shippingTrackingNumber}` → 주문이 배송중이 된다 |
| 판매자 직접 취소 | `POST /api/v3/shopping-fep/order-products/{orderProductId}/seller-cancel` `{deliveryPenaltyCharger, reason}` |
| 반품 승인 | `POST /api/v3/shopping-fep/claims/{claimId}/return/approval` |

## 알아둘 규칙

- **결제완료 상태에서 고객이 취소하면 즉시 환불되고 판매자에게 알림도 클레임도 없다.** 상품준비중·발송지연 상태에서 취소를 요청하면 승인/거절을 해야 한다.
  → 주문을 가져온 뒤 **공급사에 발주하기 전에** 한 번 더 [주문 가져오기]를 눌러 취소 여부를 확인한다.
- 발송 지연은 **주문 상품당 1번만**, 발송 예정일은 **오늘 기준 1일 이상 32일 이하**. 지연 뒤에는 결제취소만 가능.
- 상품 등록 후 **검수**를 거친 뒤에 노출된다 (`inspectionStatus`: COMPLETE / REJECT, 반려 사유는 상품 조회 v3로 확인).
- 상품명은 `[0-9a-zA-Z가-힣 ()-·[]/&+,~.*_#]` 문자만 100자까지. 검색 키워드는 글자·숫자만 10자 이하.
- 옵션 이름·값은 카테고리 템플릿의 `categorySalesOptions`와 정확히 맞아야 한다 (단위가 있으면 `3kg`처럼 단위를 붙인다).
- 주문 응답에 `productManagementCode`, `productItemManagementCode`가 들어와서, 등록할 때 넣은 `agri-상품번호`, `agri-옵션번호`로 우리 옵션을 찾는다.
