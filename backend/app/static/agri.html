농산물 판매 관리

공급사 상품을 오픈마켓에 팔고, 주문이 오면 공급사에 발주하는 일을 한곳에서 관리합니다.

이번 달

불러오는 중...

지금 할 일

    처음 쓰는 순서

    1. 설정에서 마켓 수수료와 품목별 최소 이익을 확인합니다. (과일 4,000원은 이미 들어가 있어요)
    2. 공급사를 등록합니다. 공급가에 택배비가 포함돼 있으면 택배비는 0으로 둡니다.
    3. 상품을 하나씩 입력하거나, 엑셀로 한꺼번에 올립니다. 마켓마다 얼마에 팔아야 하는지 자동으로 나와요.
    4. 스마트스토어에 상품을 올릴 때 표시 문구 버튼으로 상품정보고시·원산지·반품 안내 문구를 복사해서 붙입니다.
    5. 주문이 오면 주문·발주에 입력하고, 발주서 엑셀을 받아 공급사에 보냅니다.
    6. 공급사가 송장번호를 채워서 보내주면 그 엑셀을 올리고, 스마트스토어 송장 일괄등록 엑셀을 받아 판매자센터에 올립니다.

    가격 계산기

    공급가와 택배비를 넣으면, 마켓 수수료를 떼고도 최소 이익이 남는 판매가를 마켓별로 계산합니다. 가공하지 않은 농산물은 부가세가 없어서 판매가에 부가세를 더하지 않습니다.

    상품

    엑셀로 한꺼번에 올리기

    ① 양식을 받아서 공급사 상품표의 내용을 옮겨 적습니다. 한 줄이 옵션 하나예요 (같은 상품명은 한 상품으로 묶입니다).
    ② 공급사를 고르고 파일을 올리면 미리보기가 나옵니다. 확인 후 [등록하기]를 누릅니다.
    같은 파일을 두 번 올려도 이미 있는 옵션은 다시 만들지 않습니다.

    상품 입력

    옵션 (판매 단위)

    택배비 칸은 공급가에 택배비가 포함이면 0. "직접 정한 판매가"를 비우면 마켓별 추천가로 팝니다.

    옵션명
    중량
    수량
    등급
    공급사 상품코드
    공급가
    택배비
    직접 정한 판매가

    표시 문구

    스마트스토어 상세 설명 맨 아래에 붙여 넣으세요. "(입력 필요)"라고 나온 곳은 상품 정보를 채우면 바뀝니다.

    주문 입력
    
        
      
    
      
    스마트스토어 주문은 아래 [스마트스토어 자동 연동]에서 가져옵니다. 다른 마켓 주문이나 자동 연동이 안 될 때만 여기에 직접 적습니다.
    
      
    
        
    
          
          
          
          
          
          
          
          
          
          
        
    
        
    
        
    
      
    
    
    

    
    
      
    
        
    스마트스토어 자동 연동 
    
      
    
      
    
        주문 가져오기: 스마트스토어의 새 주문과 고객의 취소·반품 요청을 가져옵니다. 스마트스토어에는 아무것도 바꾸지 않습니다.
    
        송장 보내기: 공급사에게 받은 송장번호를 스마트스토어에 입력(발송 처리)합니다. 목록에서 주문을 고르면 그 주문만, 고르지 않으면 "송장 받음" 주문 전부를 보냅니다.
    
        취소·반품 요청이 온 주문은 목록에 빨간 표시가 뜹니다. 공급사 출고 여부를 확인한 뒤에 [승인]을 누르세요.
      
    
      
    
        
        
      
    
      
    
      
    
        
    연습용 주문 만들기 (연습 모드에서만 보입니다): 고객이 주문한 것처럼 가짜 주문을 만들고, 위의 [주문 가져오기]로 가져오는 연습을 합니다. 실제 스토어와는 상관없습니다.
    
        
    
          
          
          
        
    
      
    
    
    

    
    
      
    
        
    롯데온 자동 연동 
    
      
    
      
    
        주문 가져오기: 롯데온의 새 주문, 반품·교환 회수 요청, 고객의 취소 요청을 가져옵니다. 새 주문은 가져온 뒤 롯데온에 "받았다(연동완료)"고 알립니다 (롯데온 규칙).
        알린 뒤에는 고객이 취소해도 바로 취소되지 않고, 우리가 [취소 승인]을 눌러야 취소됩니다.
    
        송장 보내기: 공급사에게 받은 송장번호를 롯데온에 입력(발송완료 통보)합니다. 보내기 전에 롯데온에서 발송 가능한 주문인지 먼저 확인합니다. 롯데온이 거절한 주문은 자동으로 다시 보내지 않습니다 (같은 내용을 반복해서 보내면 이 컴퓨터가 차단될 수 있습니다).
    
        반품·교환은 롯데온에 승인 절차가 없고, 고객이 접수하면 바로 회수가 진행됩니다. 공급사와 회수 일정을 잡아 주세요.
      
    
      
    
        
        
      
    
      
    
      
    
        
    연습용 주문 만들기 (연습 모드에서만 보입니다): 고객이 주문한 것처럼 가짜 주문을 만들고, 위의 [주문 가져오기]로 가져오는 연습을 합니다. 실제 롯데온과는 상관없습니다.
    
        
    
          
          
          
        
    
      
    
    
    

    
    
      
    
        
    주문 목록
    
        
    
          
          
        
    
      
    
      
    
        ① 발주서 엑셀 받기: 고른 주문을 공급사별 엑셀로 내려받고 "발주 완료"로 바꿉니다. 공급사에 보내면서 마지막 두 칸(택배사, 송장번호)을 채워 달라고 하세요.
    
        ② 송장 엑셀 올리기: 공급사가 채워서 보낸 엑셀을 올리면 송장번호가 주문에 들어갑니다.
    
        ③ 스마트스토어 송장 엑셀 받기: 판매자센터 [발송처리]의 엑셀 일괄발송에 올릴 파일입니다. 올린 뒤 [마켓 입력 끝]을 누르세요.
    
        출고가 늦어지면 가짜 송장번호를 넣지 말고 판매자센터의 "발송 지연" 처리를 하세요. 가짜 송장은 판매 정지 사유입니다.

    마켓 수수료 (%)
    
      
    부가세를 포함한 대략값이 들어가 있습니다. 각 마켓 판매자센터에서 농산물 카테고리의 실제 수수료를 확인한 뒤 고쳐 주세요.
        여기 값을 바꾸면 모든 상품의 추천 판매가가 다시 계산됩니다. (이미 들어온 주문의 이익은 바뀌지 않습니다)
    
      
    
    
    
    
    
      
    품목별 최소 이익 (원, 주문 1건 기준)
    
      
    과일 4,000원은 확정된 값입니다. 채소·쌀·잡곡·기타는 정하시기 전까지 임시로 3,000원입니다.
    
      
    
    
    
    
    
      
    롯데온 등록 설정 입점 후 입력
    
      
    상품을 롯데온에 올리고 주문을 연동할 때 쓰는 값입니다. 롯데온 입점이 끝나면 판매자센터에서 확인해 넣습니다.
        롯데온 연결 확인을 누르면 인증키와 서버 IP가 맞는지 확인하고 거래처번호를 알려 줍니다 (연습 모드에서는 가짜 값). 비어 있는 칸은 상품 탭의 '롯데온 등록' 점검에서 알려 드립니다.
    
      
    
        
        
      
    
      
    
      
    카테고리 번호 (품목마다 표준카테고리와 전시카테고리가 필요합니다)
    
      
    
      
    상품정보고시 항목코드 (농수축산물 고시의 각 항목에 해당하는 롯데온 코드. 롯데온 설명서의 상품정보고시 PDF에서 확인합니다. 모르는 항목은 비워도 됩니다)
    
      
    
      
    
    
    
    
      
    스마트스토어 등록 설정
    
      
    상품을 스마트스토어에 올릴 때 쓰는 값입니다. 카테고리 번호는 스마트스토어센터 상품등록 화면에서 해당 품목의 세분류를 골라 확인하세요.
        비어 있으면 상품 탭의 '스마트스토어 등록' 점검에서 알려 드립니다.
    
      
    
      
    
        
        
        
        
        
      
    
      
    
    
    
    
      
    기타
